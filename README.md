# 🎨 Text-to-Image Generation

A basic Text-to-Image Generation project using a Hugging Face model.

## 📌 About

This project allows users to enter a text prompt and generate an image based on the given description.

## ✨ Features

- 📝 Enter a text prompt
- 🤖 Hugging Face model integration
- 🖼️ AI-generated images
- 🔗 Simple and basic implementation

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Hugging Face

## 🎯 Purpose

This project was created to understand the basic integration of a Hugging Face Text-to-Image model and explore AI-based image generation.

## 🚀 How It Works

1. Enter a text prompt.
2. The prompt is sent to the Hugging Face model.
3. The model generates an image.
4. The generated image is displayed to the user.
